# Icon Instructions

Place your icon files in this folder before building:

| File            | Size            | Used for                                   |
| --------------- | --------------- | ------------------------------------------ |
| `icon.ico`      | 256×256 min     | Windows app icon, taskbar, ALT+TAB         |
| `icon.icns`     | 512×512 min     | macOS dock icon                            |
| `icon.png`      | 512×512         | Linux + electron-builder conversion source |

> **Note:** On Windows builds, electron-builder automatically converts `icon.png`
> to `icon.ico` if `icon.ico` is absent. So you only *need* the PNG for Windows.
> The `icon.ico` file is used for embedding the icon in the `.exe` header and
> on the Windows taskbar, so replacing it with a real high-quality ICO is
> recommended before release.

---

## How to create icons

1. Design your icon at **512×512 pixels** (PNG, transparent background).
2. Save it as `icon.png` in this folder.
3. Use <https://www.icoconverter.com> to generate `icon.ico` from your PNG.
   - Select all size options (16, 32, 48, 64, 128, 256).
4. Use <https://cloudconvert.com/png-to-icns> to generate `icon.icns`.
5. Replace the placeholder files with your real files.
6. Rebuild: `cd electron-installer && npm run build`

---

## Placeholder files

The current `icon.ico` and `icon.png` in this folder are **placeholder files**
generated by `scripts/generate-placeholder-icon.js`. The app will build and run
with them. Replace them with your real AxiomPips icon before shipping.

To regenerate the placeholders at any time:

```
cd electron-installer
npm run generate-icons
```

## For the installer (header and sidebar images)

These are **optional** — the installer runs without them.

| File                   | Size          | Shown on                        |
| ---------------------- | ------------- | ------------------------------- |
| `installerHeader.bmp`  | 150×57 px     | Top of each installer page      |
| `installerSidebar.bmp` | 164×314 px    | Welcome and Finish pages        |

The existing files in `electron-installer/assets/` are pre-generated placeholders.
Run `electron-installer/assets/generate-installer-images.py` to create new ones.
